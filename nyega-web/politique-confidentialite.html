2. Principes Fondamentaux et Minimisation des Données

NyeGa s'engage à respecter scrupuleusement la législation togolaise relative aux données personnelles. Nous appliquons le principe de minimisation stricte :

  • Données de compte : Adresse email, nom/prénom (ou pseudonyme), mot de passe chiffré par algorithme irréversible.
  • Données budgétaires déclaratives : Montant du budget alloué pour le mois en Francs CFA (FCFA), liste des dépenses déclarées volontairement par l'étudiant.
  • Ce que nous ne collectons PAS : Aucun numéro de carte bancaire, aucun code secret TMoney / Flooz, aucun relevé bancaire automatique, aucune géolocalisation continue.

3. Traitement par Intelligence Artificielle (Edge Function)

Afin de proposer une catégorisation automatique sans ressaisie manuelle fastidieuse :

  • Seule la description textuelle courte (max. 100 caractères, ex: « pass data moov ») est transmise de manière chiffrée (TLS 1.3).
  • Aucun nom, email, ni montant financier n'est jamais transmis au modèle d'intelligence artificielle.
  • Aucune donnée n'est exploitée pour l'entraînement de modèles tiers ou pour du ciblage commercial.
